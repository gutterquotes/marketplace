- Primary mark: black horizontal `GutterQuotes.com` wordmark.

## Typography

- Primary font: Inter.
- Fallbacks: Arial or sans-serif on global site styles; Helvetica Neue, Helvetica, Arial in the ultra-minimal quote section.
- Headings: heavy, tight, black. Live CSS uses weights around 760-850 with tight line-height.
- Buttons: pill-shaped, white text on orange, heavy label weight.

## Messaging

- Primary headline pattern: "One request. Multiple gutter quotes."
- Support copy: free quote request, local pros, no obligation, no pressure.
- Service scope: gutter installation, gutter guards, gutter replacement, gutter repair, gutter cleaning, downspouts, yard drainage.
