# Product Brief

## Positioning

Gutter Quotes helps homeowners compare trusted gutter professionals nationwide without browsing a directory first.

## Primary Users

- Homeowners who need installation, replacement, repair, cleaning, guards, drainage, fascia or soffit work, commercial service, or emergency repair.
- Gutter companies and independent installers that want qualified project requests.

## Core Conversion Path

1. Homeowner enters location and service need.
2. Homeowner completes a short project intake.
3. Installers browse or receive matching project requests.
4. Installers respond with offers or questions.
5. Homeowner compares offers by price, reviews, warranty, verification, and availability.
6. Homeowner hires a provider.
7. Marketplace captures review and project outcome.

## Launch Revenue Model

Start free to build marketplace liquidity nationwide. Keep the architecture ready for:

- qualified lead fees
- installer memberships
- optional payment commissions
- verified provider premium placement

## First Custom Features After Template Setup

- Dedicated quote-request page separate from generic listing inquiry.
- Provider matching logic based on service type, ZIP/state coverage, radius, verification, availability, and max active leads.
- Provider lead inbox with workflow states.
- Admin review queue for provider verification.
- Local SEO pages for high-intent city and service combinations.
